# Lista de Tarefas (Taskflow)

O objetivo é praticar a criação de repositórios, organização de diretórios, uso de branches, commits, Pull Requests, merge e resolução de conflitos.

## Tecnologias Utilizadas
Projeto desenvolvido em HTML, CSS e JavaScript.

## Como Executar
1. Clone este repositório: `git clone https://github.com/joaogula11-ctrl/taskflow-equipe-JGRG.git`
2. Abra a pasta do projeto no seu editor de código.
3. Abra o arquivo `src/index.html` no seu navegador (ou use a extensão Live Server no VS Code).
